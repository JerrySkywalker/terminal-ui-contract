# Changelog

## Unreleased

Adds `terminal-ui-cliclack` 0.1.0 as a Git-only workspace package for inline
select, multi-select, input, confirmation and progress. Core, Runtime and
Ratatui retain their registry versions.

## 0.2.0

Core preserves the 0.1 public APIs and adds neutral input, Standard/Vim
modal keymaps with typed intents and TOML overlays, pane focus, bounded
viewports, responsive policy, semantic documents and themes.

The same source release also provided `terminal-ui-runtime` 0.1.0 and
`terminal-ui-ratatui` 0.1.0 on crates.io.

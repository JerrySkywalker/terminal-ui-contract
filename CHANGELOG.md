# Changelog

## 0.2.0 candidate (unreleased)

Root Core preserves the eight 0.1 modules and all existing public behavior. Adds
neutral input, Standard/Vim modal keymap with typed intents and TOML overlays,
pane focus, bounded viewports, responsive policy, semantic documents and themes.
Adds separate terminal-ui-runtime 0.1.0 and terminal-ui-ratatui 0.1.0 packages.
No product migration or registry publication is implied.
